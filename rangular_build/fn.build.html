pub fn build(config: Config)
Expand description

Discover and compile a package’s rangular templates and styles.

Reads CARGO_MANIFEST_DIR and OUT_DIR, writes generated Rust under OUT_DIR/rangular, writes CSS to the configured output path, and emits Cargo rerun directives for the component directory and optional global stylesheet. Panics with the offending path and compiler diagnostics on failure, as expected for a Cargo build script.

§Arguments

  • config - Component source directory, generated CSS path, and optional global SCSS path. Paths are relative to the Cargo package root.

§Panics

Panics when CARGO_MANIFEST_DIR or OUT_DIR is missing, when no matching components are found, when a template or stylesheet fails to compile, or when an input or output file cannot be read or written.

§Examples

In a package’s build.rs:

use rangular_build::{Config, build};

fn main() {
    build(Config::new("src/components", "style/components.css"));
}
