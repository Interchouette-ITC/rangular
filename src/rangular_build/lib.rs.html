1//! Cargo build-script support for compiling rangular HTML templates and SCSS.
2//!
3//! Configure the component directory and generated CSS path in `build.rs`, then
4//! call [`build`] before the application crate is compiled. Each immediate
5//! subdirectory containing a matching `<name>.html` file is compiled to an
6//! includeable Rust view under Cargo's `OUT_DIR/rangular/`. A matching
7//! `<name>.scss` file is compiled into the generated stylesheet.
8//!
9//! Application-level document templates are declared on the same [`Config`]
10//! with [`Config::document`], [`Config::head`], and [`Config::body`]. They go
11//! through the same AOT compiler and generate `<file-stem>_view.rs` next to the
12//! component views; the head template uses the head compiler, optionally with a
13//! [`HeadComponentAdapter`].
14//!
15//! # Example
16//!
17//! ```no_run
18//! use rangular_build::{Config, build};
19//!
20//! fn main() {
21//!     build(
22//!         Config::new("src/components", "style/components.css")
23//!             .global_scss("style/site.scss")
24//!             .document("src/document/document.html")
25//!             .head("src/document/head.html")
26//!             .body("src/document/body.html"),
27//!     );
28//! }
29//! ```
