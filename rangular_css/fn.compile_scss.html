pub fn compile_scss(scss: &str) -> CssResult
Expand description

Compile component SCSS to flat CSS without emulated _ngcontent / _nghost attributes. Use this when the DOM does not carry those attrs (typical Leptos CSR). Bare :host rules are dropped.
